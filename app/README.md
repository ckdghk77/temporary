# 22_summer_indiv_reserach

#### 폴더

templates: 5개의 html 파일 (alert, complete, consent, error, experiment)     
consent, alert는 실험 전 안내, experiment는 실험 실행, error는 실험 중 에러, complete는 실험 종료 안내     

statics: css, js, img, lib 폴더   
-css 폴더는 niv lab 제공 css라 사용하지 않음  
-js 폴더: instruction.js는 instruction과 tutorial에 사용하는 플러그인, oneshot.js는 observation에 사용하는 플러그인,    
oneshot_triangle.js는 tri_rating에 사용하는 플러그인, oneshot_cue.js는 실험에 사용되는 이미지 경로 저장,    
oneshot_stimulus는 각 라운드에 사용되는 랜덤 이미지와 리워드 선택,     
nivturk_plugins.js (mturk 용) 는 에러 또는 종료 페이지로 경로 재설정하고 디스크에 데이터 저장   
-img 폴더: 실험에 사용되는 이미지들    
-lib 폴더: version 6.3.1.을 사용, version 6.3.1.의 image-slider-response.js는 linking and causal rating에 사용되는 플러그인    

#### 실행

http://aibrain-experiment.kaist.ac.kr/?workerId=<> 접속 또는 다운로드 후 experiment.html 실행
